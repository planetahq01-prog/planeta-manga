A biblioteca de mangás já está conectada. Informe o mesmo código de acesso do Planeta HQ para começar a ler.

Como conseguir isso?
  1. No console de administração, crie um projeto e ative a biblioteca API.
  2. Em "Credenciais", crie uma Chave de API e restrinja-a à Drive API. Essa chave NÃO é digitada aqui: ela fica guardada como segredo (DRIVE_API_KEY) dentro do proxy de conteúdo, nunca no app.
  3. No biblioteca, clique com o botão direito na pasta raiz das mangás → Compartilhar → mude para "Qualquer pessoa com o link" → "Leitor". Isso é necessário para o app ler os arquivos sem exigir login de cada usuário.
  4. Abra a pasta no navegador; o ID é o trecho da URL depois de /folders/.
  5. Se ao abrir uma mangá der erro Failed to fetch, o navegador está bloqueando o download do conteúdo do arquivo por CORS (isso acontece com PDF/CBR mas não com a listagem, que é só metadado). Cole ali a URL de um proxy de conteúdo — veja o texto abaixo do formulário para o código pronto.
  6. Cole os valores acima. Eles ficam salvos só neste dispositivo. Toda consulta ao biblioteca passa pelo seu proxy de conteúdo, que é quem guarda a chave de API.
